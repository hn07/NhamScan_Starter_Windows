NHAM SCAN - BAN SUA LOI GIAI NEN

1. Giai nen ZIP nay.
2. Chay INSTALL_NHAM_SCAN_FIX.bat.
3. Bo cai tai ma nguon vao D:\MyWorkSpace\NhamScan, giai nen trong chinh thu muc nay va sao chep bang robocopy.
4. Chay D:\MyWorkSpace\NhamScan\RUN_NHAM_SCAN.bat.

Neu van loi:
- Kiem tra Windows Security / Controlled folder access hoac antivirus co chan PowerShell/robocopy khong.
- Khong can chay Administrator ngay tu dau.
- File ZIP tai ve duoc giu tai D:\MyWorkSpace\NhamScan\scanner-source.zip de kiem tra.
